## The Idea
This Launcher was inspired by **android pattern locks**, so it has simmular functionality. 

You can drag on the grid, to **open folders** and **navigate throw your apps**. Then you can **release to start** the app you want.

## Current features
- Pattern pad
  - drag on the pattern pad  
  - drag over folders to open them
  - release to start the app under your pointer
- Design
  - digital clock display
  - minimalistic design
- app placement on the pattern pad is saved in a config file (json)
